# JenpyROQ
This repository implements an extended, modularised and streamlined version of the PyROQ code, forked in March 2022 from its [original repository](https://github.com/qihongcat/PyROQ) and initially developed at the Theoretisch-Physikalisches Institut of the Friedrich-Schiller-Universität Jena.

Older history is available in [this fork](https://github.com/bernuzzi/PyROQ/tree/master/PyROQ).

# Documentation

Documentation is available at: [JenpyROQ documentation](https://gcarullo.github.io/JenpyROQ/).
